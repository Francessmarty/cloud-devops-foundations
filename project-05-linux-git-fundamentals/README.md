# Project 5 Linux + Git + GitHub Fundamentals

This project documents my hands-on learning of Linux command line basics and Git/GitHub version control workflows.

## What I learned 
- Navigating Linux directories and files (pwd, ls, cd, mkdir, touch, mv, rm)
- File permissions (chmod, executable scripts)
- Creating and running bash scripts
- Git workflows (init, status, add, commit, branch)
- Connecting local code to GitHub (remote origin, push, pull)

## Project structure
- `notes/` → learning notes and explanations
- `scripts/` → bash scripts created during practice
- `logs/` → command outputs and sample log files
- `screenshots/` → evidence screenshots (steps, outputs, GitHub results)

## Evidence screenshots naming convention
Screenshots are saved as:
- `01-project-5-folder-created.png`
- `02-project-5-structure.png`
- `03-project-5-readme-open.png`
