# Project 5: Linux & Git Fundamentals (Notes)

## Objective
To understand and practice basic Linux commands and Git workflows used in Cloud and DevOps environments.

## Linux Commands Practiced
- pwd: show current directory
- ls: list files and directories
- mkdir: create directories
- touch: create files
- mv: rename or move files
- chmod: change file permissions
- cat:  view file content

## Git Commands Practiced
- git status: check repository state
- git add:  stage files
- git commit: save changes
- git push: upload to GitHub
- git clone:  copy remote repository

## Key Learnings
- Linux commands are used to manage files and directories efficiently
- Git tracks changes at file level, not folders
- Screenshots help prove hands-on work
- Proper folder structure improves project clarity
- README and notes are critical for documentation
