# Project 7: GitHub Collaboration, Issues, PRs & Actions CI

## Objective
Demonstrate practical GitHub collaboration features:
- Issues
- Branches
- Pull Requests
- Merge workflow
- GitHub Actions CI

## What was done
- Created a GitHub Issue to track work
- Created a feature branch
- Added documentation changes
- Opened and merged a Pull Request
- Configured a basic GitHub Actions CI workflow
- Verified CI ran successfully

## Outcome
This project shows how real teams collaborate using GitHub workflows and automated CI pipelines with GitHub Actions.
